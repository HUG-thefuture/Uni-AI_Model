## 一、本轮完成

### 1. 可访问性与移动端

- 为输入框、下拉框和文本域补齐可见标签及对应关系。
- 为当前导航、筛选项、模式选择和比例选择补齐 `aria-current` / `aria-pressed`。
- 移动端菜单同步 `aria-expanded`、`aria-hidden` 和 `inert`；支持 Escape 关闭并把焦点还给菜单按钮。
- 390px 视口下常用按钮和表单控件最小触控高度调整为 44px。
- 页面只保留一个一级标题；页面切换时同步浏览器标题。
- 调整次要文字、状态和占位文字颜色，增加减少动态效果与强制颜色模式适配。

### 2. 输入与跳转安全

- 个人资料、任务标题、模型名称、余额和状态等动态文本写入页面前统一规范化或转义。
- 从本地存储恢复演示资料时先校验类型，避免异常值破坏页面。
- 非演示模式的登录跳转只允许 HTTP(S) 地址。
- 用含 HTML 标签的姓名和学校完成回归：标签按普通文本显示，未创建额外 DOM 节点。

### 3. 交互完整性与性能

- 创作历史中的“查看”按钮可跳转到对应图像、声音或视频页面。
- 清空演示历史前增加确认；没有实际行为的聊天历史按钮改为非按钮展示。
- 删除 8 个页面中未使用的 Layui JavaScript 请求，继续保留本地 Layui CSS 与图标字体。
- 增加未启用 JavaScript 时的明确提示。
