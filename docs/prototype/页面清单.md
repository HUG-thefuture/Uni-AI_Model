# 成员3页面清单

本清单对应《四川高校AI大模型门户》WBS中的门户前端工作包；页面以静态演示优先，待后端接口稳定后切换真实数据。

| 页面 | 文件 | 已覆盖内容 | 联调依赖 |
| --- | --- | --- | --- |
| 门户首页 | `frontend/index.html` | 快捷入口、模型推荐、演示模式标识 | 无 |
| 登录注册 | `frontend/auth.html` | 用户名密码登录、注册校验、短信通道待接口提示 | `/api/auth/register`、`/api/auth/login` |
| 模型广场 | `frontend/models.html` | 模型筛选、搜索、进入应用 | `/api/models` |
| 文本交互舱 | `frontend/chat.html` | 模型切换、会话、演示回答 | 文本任务与流式输出接口 |
| 图像生成室 | `frontend/image.html` | 提示词、比例、任务四态演示 | 图像任务接口 |
| 声音创作坊 | `frontend/audio.html` | 音色选择、文本提交、任务演示 | 音频任务接口 |
| 视频合成站 | `frontend/video.html` | 时长选择、提交、进度状态演示 | 视频任务接口 |
| 创作历史 | `frontend/tasks.html` | 状态、查看、失败重试演示 | 任务列表、详情、重试接口 |
| 个人中心 | `frontend/profile.html` | 资料编辑、认证/余额入口 | 用户资料、钱包接口 |

暂未建设的页面：管理端用户管理、订单/发票、API Key管理、调用统计。它们需要成员1或成员4明确接口及权限口径后接入。
