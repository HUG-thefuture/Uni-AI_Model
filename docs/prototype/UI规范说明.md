# 门户 UI 规范说明

## 目标

保持参考站的“统一AI工具门户”使用路径：先选能力，再提交创作，最后在任务历史查看结果；不复制参考站的源代码或素材。

## 视觉与布局

- 主色：`#2f6fe8`，用于主按钮、激活状态和关键反馈。
- 页面底色：`#f3f6fb`；内容面板为白色，使用细边框和柔和阴影区分层级。
- 桌面端为顶栏、左侧导航和内容区；900px以下收起为可打开的侧栏。
- 表单控件、主要按钮在手机端最小高度44px，键盘焦点使用清晰蓝色描边。

## 交互状态

- 演示模式仅模拟任务处理与失败重试，不向第三方模型服务发送请求。
- 未提供后端接口的功能必须标为“待接口/待开放”，不得模拟成功结果。
- 登录注册页面的账号密码通道对接真实接口；短信验证码接口缺失时显示说明，不伪造验证码流程。
- 账户下拉菜单支持点击、方向键、Home/End、Esc和点击外部关闭；真实模式下调用退出接口并清除本地令牌。

## 联调约定

- 统一响应以 `code === 0` 代表成功，令牌保存键为 `ai_portal_token`。
- 页面通过 `window.PortalConfig` 配置 `apiBase`、`demoMode`、`loginUrl`；当前仓库默认走真实认证接口，离线验收时再显式开启演示模式。
- 接口返回401时清除本地令牌并跳转登录页；仅允许回到门户内已知页面，避免开放跳转。
