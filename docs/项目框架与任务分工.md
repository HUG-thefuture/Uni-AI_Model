## 一、总体技术架构

```text
浏览器（Layui 前端）
   │  Ajax/JSON
   ▼
FastAPI 接口层（/api 统一前缀）
   │  SQLAlchemy
   ▼
MySQL（ai_portal 库）

AI 能力：统一 ModelProvider 适配层
  OnlineProvider / LocalProvider / MockProvider（Demo 并入 Mock）
  长耗时任务四态：待处理 → 处理中 → 成功 / 失败

部署链路：域名/IP → Nginx(80/443) → Uvicorn/Gunicorn → FastAPI → MySQL
   Supervisor 守护与自动重启；配置全部走环境变量
```

统一规范（已冻结，所有接口必须遵守）：

- 前缀 `/api`；返回结构 `{code, message, data, request_id}`；错误码 400/401/403/404/409/429/500
- 认证：JWT Bearer Token，24h 过期；每次请求校验用户存在且 `status=1`
- 权限：普通用户只能访问自己的资源；管理接口统一 `require_admin`
- 金额：整数（分），禁止浮点；密码：哈希存储，禁止明文
- 模型失败不得扣费；失败调用必须可重试且不重复扣费
- Python 统一 **3.11.9**（仓库根目录 `.python-version`），每人用虚拟环境

## 七、结构变更登记规则（防止再次脱节）

1. **新增文件/目录必须先在本文件"三、目录归属与状态对照"登记**，注明归属成员和状态，再提交代码。
2. **sql 脚本统一命名**：`3 位序号_成员_用途.sql`，如 `001_member1_users.sql`、`002_member2_models_ai_tasks.sql`、`003_member4_wallets.sql`。
3. **交付记录统一放** `交付记录/dayN—交付/`，文件名带成员号，如 `成员1-第一天交付记录.md`。
4. **providers 固定四类**：Online / Local / Mock / factory 分发；不再新增 Provider 类型，Demo 类能力并入 Mock。
5. **core 目录**：security.py、deps.py 由成员1 8/30 补建，其它成员不得在 core 另起新文件。
6. 前端页面**只建框架清单里的 8 个页面**，新增页面需先登记。
