## 一、总体技术架构

```text
浏览器（Layui 前端）
   │  Ajax/JSON
   ▼
FastAPI 接口层（/api 统一前缀）
   │  SQLAlchemy
   ▼
MySQL（ai_portal 库）

AI 能力：统一 ModelProvider 适配层
  OnlineProvider / LocalProvider / DemoProvider / MockProvider
  长耗时任务四态：待处理 → 处理中 → 成功 / 失败

部署链路：域名/IP → Nginx(80/443) → Uvicorn/Gunicorn → FastAPI → MySQL
   Supervisor 守护与自动重启；配置全部走环境变量
```

统一规范（已冻结，所有接口必须遵守）：

- 前缀 `/api`；返回结构 `{code, message, data, request_id}`；错误码 400/401/403/404/409/429/500
- 认证：JWT Bearer Token，24h 过期；每次请求校验用户存在且 `status=1`
- 权限：普通用户只能访问自己的资源；管理接口统一 `require_admin`
- 金额：整数（分），禁止浮点；密码：哈希存储，禁止明文
- 模型失败不得扣费；失败调用必须可重试且不重复扣费

## 二、项目目录框架（Gogs: mac/ai-portal）

```text
ai-portal/
├── backend/                  # 成员2/4：FastAPI 后端
│   ├── app/
│   │   ├── main.py           # 应用入口
│   │   ├── core/             # 配置、安全、依赖（config/security/deps）
│   │   ├── models/           # SQLAlchemy 模型
│   │   ├── schemas/          # Pydantic 请求/响应模型
│   │   ├── routers/          # 路由：auth/user/admin/models/tasks/wallet/order/api_key/stats
│   │   ├── services/         # 业务逻辑（扣费事务、统计等）
│   │   └── providers/        # ModelProvider 适配层（Base/Online/Local/Demo/Mock）
│   ├── tests/                # 接口测试
│   ├── requirements.txt
│   └── .env.example          # 环境变量模板（真实密钥不入库）
├── frontend/                 # 成员3：Layui 前端
│   ├── index.html            # 门户首页
│   ├── models.html           # 模型广场
│   ├── chat.html             # 文本对话
│   ├── image.html            # 图像生成
│   ├── audio.html            # 声音生成
│   ├── video.html            # 视频生成
│   ├── tasks.html            # 任务中心/历史记录
│   ├── profile.html          # 个人中心
│   ├── css/                  # 公共样式
│   └── js/                   # layui 配置、ajax 封装、公共组件
├── sql/                      # 数据库脚本（初始化 DDL、示例数据）
├── docs/                     # 数据字典、接口约定表、部署文档、测试用例
├── scripts/                  # 部署、备份、恢复脚本
└── README.md
```
