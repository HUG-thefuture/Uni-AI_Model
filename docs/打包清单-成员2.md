# 打包清单 · 成员2(模型与 AI 任务)交付物

版本 2026-08-29 ｜ 负责人:成员2 ｜ 产物名:**成员2-源代码.zip**

> 目标:把成员2 范围内的源代码与文档打成单个 zip 交付/演示,包内不含任何密钥、本地垃圾文件与测试私有文件。

## 1. 打包范围与排除项

**纳入**(仓库根目录执行):

- `backend/app/`(全部源码)
- `backend/scripts/`(seed_models / seed_demo / test_m_series 等)
- `backend/assets/`(samples 演示样例与 manifest.json)
- `backend/requirements.txt`、`backend/.env.example`(模板,不含真实值)
- `docs/`(api.md、model-config-final.json、数据字典、对接提醒、打包清单等)

**排除**(红线:密钥与本地环境绝不进包):

| 排除项 | 原因 |
| --- | --- |
| `.env`(backend/.env) | 可能含 SILICONFLOW_API_KEY / 数据库密码,只留 .env.example |
| `.git/`、`.venv/` | 版本库与虚拟环境,体积大且不可移植 |
| `__pycache__/`、`*.pyc`、`.pytest_cache/` | Python 缓存垃圾 |
| `backend/uploads/` | 运行期上传落盘目录(含 /static 生成的文件) |
| `backend/*.db`(demo.db、test_ai_portal.db 等) | 本地 sqlite 演示库,接收方用 seed 脚本重建 |
| `backend/tests/` | 本地验证用私有测试,不进交付包 |
| `*.log`、`nohup.out` 等运行日志 | 本地运行痕迹 |

## 2. 打包命令

### 2.1 PowerShell(Windows)

```powershell
# 仓库根目录执行;先同步到暂存目录剔除排除项,再压缩
cd C:\UGit\Uni-AI_Model
$staging = "$env:TEMP\member2-pack"
Remove-Item $staging -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path $staging | Out-Null

robocopy backend "$staging\backend" /E ^
  /XD .git .venv __pycache__ .pytest_cache uploads tests ^
  /XF .env *.db *.pyc *.log
robocopy docs "$staging\docs" /E /XD __pycache__

Remove-Item .\成员2-源代码.zip -Force -ErrorAction SilentlyContinue
Compress-Archive -Path "$staging\*" -DestinationPath .\成员2-源代码.zip -Force
Remove-Item $staging -Recurse -Force

# 自检:确认包内无 .env / *.db / __pycache__
Expand-Archive .\成员2-源代码.zip "$env:TEMP\member2-check" -Force
Get-ChildItem -Recurse "$env:TEMP\member2-check" -Include .env,*.db,*.pyc | Should-Be-Empty   # 手工确认输出为空
Remove-Item "$env:TEMP\member2-check" -Recurse -Force
```

### 2.2 Git Bash / Linux / macOS

```bash
cd /c/UGit/Uni-AI_Model   # Windows Git Bash 路径;Linux/macOS 为仓库路径

rm -f 成员2-源代码.zip
zip -r 成员2-源代码.zip \
  backend/app backend/scripts backend/assets \
  backend/requirements.txt backend/.env.example \
  docs \
  -x "*/__pycache__/*" -x "*.pyc" -x "*/.pytest_cache/*" \
  -x "backend/.env" -x "backend/*.db" -x "backend/uploads/*" \
  -x "backend/tests/*" -x "*.log"

# 自检:以下命令应无任何输出
unzip -l 成员2-源代码.zip | grep -E "\.env$|\.db$|__pycache__|\.pyc|backend/tests/"
```
