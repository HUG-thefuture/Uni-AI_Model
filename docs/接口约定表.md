# AI 大模型门户 · 接口约定表（成员1 · 8/29 交付）

版本 v1.0 ｜ 日期 2026-08-29 ｜ 维护人：成员1（用户与集成）

## 一、统一规范（全组冻结）

| 项目 | 约定 |
| --- | --- |
| 接口前缀 | `/api`，前后端分离；前端禁止直连第三方模型 |
| 成功返回 | `{"code":0,"message":"success","data":{},"request_id":"..."}` |
| 失败返回 | 正确 HTTP 状态码 + `{"code":非0,"message":"错误说明","data":null,"request_id":"..."}` |
| HTTP 状态码 | 400 参数错误；401 未登录/凭证失效；403 无权限；404 不存在；409 冲突；429 限流；500 服务异常 |
| request_id | 每次请求生成 UUID，随日志记录，用于链路排查 |
| 认证 | JWT Bearer Token（`Authorization: Bearer <token>`），有效期 24h；每次请求校验用户存在且 `status=1`，禁用立即失效 |
| 退出登录 | 无状态 JWT：客户端删除本地 token；如需服务端失效，维护 token 黑名单/用户 token 版本号（本期客户端删除即可） |
| 权限 | 普通用户只能访问自己的资源（按当前登录 user_id 过滤）；管理接口统一 `require_admin` |
| 分页 | 通用 `page`（默认1）、`page_size`（默认10，最大100）；返回 `{total, page, page_size, items}` |
| 时间格式 | `YYYY-MM-DD HH:MM:SS`（UTC+8） |
| 金额 | 整数（分），禁止浮点 |

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |

## 三、接口明细

### 1. POST /api/auth/register

- 请求体：`{ "username": "student01", "password": "Passw0rd123", "school": "四川大学", "nickname": "小王" }`
- 成功 201：`data` 返回 `{id, username, role, status, real_auth_status, school, created_at}`，不返回 password_hash
- 错误：400 参数缺失/密码强度不足；409 用户名已存在
- 规则：明文密码仅出现在本请求，服务端哈希后入库；注册事务内同步创建 `user_profiles` 和 `wallets`（余额 0）

### 2. POST /api/auth/login

- 请求体：`{ "username": "student01", "password": "Passw0rd123" }`
- 成功 200：`data` 返回 `{token, user:{id, username, role, status, real_auth_status, school}}`
- 错误：401 用户名或密码错误（不区分账号是否存在）；403 账号已被禁用
- 规则：登录成功记录 request_id 与日志；登录接口做基础限流（防暴力破解，P1）

### 3. POST /api/auth/logout

- 请求头：Bearer Token
- 成功 200：`data` 返回 `{}`
- 错误：401 未登录
- 规则：客户端删除本地 token；本期服务端不强制维护黑名单

### 4. GET /api/auth/me

- 请求头：Bearer Token
- 成功 200：`data` 返回 `{id, username, role, status, real_auth_status, school, profile:{nickname, avatar_url, phone, email, major, bio}, wallet:{balance, total_recharged, total_consumed}, created_at}`
- 错误：401 未登录/账号已禁用
- 规则：只返回当前登录用户自己的信息

### 5. PUT /api/user/profile

- 请求体：`{ "nickname": "新昵称", "avatar_url": "...", "phone": "...", "email": "...", "major": "...", "bio": "..." }`（均可选）
- 成功 200：`data` 返回更新后的 profile 字段
- 错误：400 参数不合法（如 phone/email 格式）；401 未登录
- 规则：后端按当前登录 user_id 定位记录，禁止接受前端传 user_id

### 6. GET /api/admin/users

- 请求：`/api/admin/users?page=1&page_size=10&keyword=川大&role=user&status=1`
- 成功 200：`data` 返回 `{total, page, page_size, items:[{id, username, role, status, real_auth_status, school, created_at}]}`
- 错误：401 未登录；403 非管理员
- 规则：`require_admin`；keyword 模糊匹配 username/school；不返回 password_hash

### 7. PUT /api/admin/users/{id}/status

- 请求体：`{ "status": 0 }`（0 禁用，1 启用）
- 成功 200：`data` 返回 `{id, status, updated_at}`
- 错误：400 status 非法；401 未登录；403 非管理员或禁止操作自己；404 用户不存在
- 规则：禁用后该用户已签发 token 立即失效（鉴权时校验 status）；建议禁止管理员禁用自己
