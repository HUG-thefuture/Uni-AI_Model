# AI 大模型门户 · 数据字典（成员1 · 8/29 交付）

版本 v1.0 ｜ 日期 2026-08-29 ｜ 维护人：成员1（用户与集成）

适用范围：本字典定义 `users`、`user_profiles`、`wallets` 三张表（成员1职责范围）。`models`、`ai_tasks`、`consumption_records` 等表由成员2/成员4另行维护。字段口径确认后，8/30 起按此实现；任何变更需登记到接口清单。

## 一、通用约定

| 约定 | 说明 |
| --- | --- |
| 数据库 | `ai_portal`，MySQL 8.0+，InnoDB，utf8mb4 |
| 主键 | `id BIGINT UNSIGNED AUTO_INCREMENT`（`wallets` 以 `user_id` 为主键） |
| 金额 | 一律 `BIGINT` 整数，单位「分」；禁止 FLOAT/DOUBLE 计算 |
| 时间 | `DATETIME`，默认 `CURRENT_TIMESTAMP` |
| 状态 | `status` 统一 `TINYINT`：1=启用/有效，0=禁用/失效 |
| 索引 | 唯一键 `uk_xxx`，普通索引 `idx_xxx` |
| 外键 | 本期使用逻辑外键（不强制建物理外键），应用层必须校验归属 |

## 二、users 用户主表

| 字段 | 类型 | 允许空 | 默认 | 约束/说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| username | VARCHAR(50) | 否 | - | 唯一 `uk_username`；3-32 位，字母/数字/下划线 |
| password_hash | VARCHAR(255) | 否 | - | 密码哈希（bcrypt/argon2），禁止明文 |
| role | VARCHAR(20) | 否 | 'user' | `user` / `admin` |
| status | TINYINT | 否 | 1 | 1 启用 0 禁用；`idx_status`；禁用后不可登录 |
| real_auth_status | TINYINT | 否 | 0 | 0 未认证 1 已认证 2 审核中（P1 实名认证预留） |
| school | VARCHAR(100) | 是 | NULL | 学校（四川高校场景） |
| created_at | DATETIME | 否 | 当前时间 | 创建时间 |
| updated_at | DATETIME | 否 | 当前时间 | 更新时间（自动更新） |

关键规则：

- `username` 唯一，注册时校验；密码只存哈希，登录错误统一提示「用户名或密码错误」。
- 登录和每次鉴权校验 `status=1`，禁用用户拒绝访问、已有登录态立即失效。
- 用户资料放 `user_profiles`，余额放 `wallets`，不在 users 表冗余。

## 三、user_profiles 用户资料表

| 字段 | 类型 | 允许空 | 默认 | 约束/说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| user_id | BIGINT UNSIGNED | 否 | - | 唯一 `uk_user_id`；逻辑外键 users.id |
| nickname | VARCHAR(50) | 是 | NULL | 昵称，默认取 username |
| avatar_url | VARCHAR(255) | 是 | NULL | 头像地址 |
| phone | VARCHAR(20) | 是 | NULL | 手机号（P2 短信验证码预留） |
| email | VARCHAR(100) | 是 | NULL | 邮箱 |
| major | VARCHAR(100) | 是 | NULL | 专业 |
| bio | VARCHAR(500) | 是 | NULL | 个人简介 |
| created_at | DATETIME | 否 | 当前时间 | 创建时间 |
| updated_at | DATETIME | 否 | 当前时间 | 更新时间 |

关键规则：`user_id` 唯一；注册事务内同步创建；普通用户只能修改自己的资料（后端按当前登录 user_id 过滤，不接受前端传 user_id）。

## 四、wallets 钱包表

| 字段 | 类型 | 允许空 | 默认 | 约束/说明 |
| --- | --- | --- | --- | --- |
| user_id | BIGINT UNSIGNED | 否 | - | 主键 + 唯一；逻辑外键 users.id |
| balance | BIGINT | 否 | 0 | 可用余额（分），禁止为负 |
| total_recharged | BIGINT | 否 | 0 | 累计充值 |
| total_consumed | BIGINT | 否 | 0 | 累计消费 |
| version | INT | 否 | 0 | 乐观锁版本号（防并发扣减） |
| created_at | DATETIME | 否 | 当前时间 | 创建时间 |
| updated_at | DATETIME | 否 | 当前时间 | 更新时间 |

关键规则：

- `user_id` 唯一；注册时初始化余额 0。
- 扣费必须在事务内 `SELECT ... FOR UPDATE` 行锁（或使用 version 乐观锁），余额不足禁止扣减且不得为负。
- 所有金额运算用整数，禁止浮点。

## 五、表间关系

| 关系 | 说明 |
| --- | --- |
| users 1:1 user_profiles | `user_profiles.user_id` 唯一 |
| users 1:1 wallets | `wallets.user_id` 唯一 |

注册事务：插入 `users` → 插入 `user_profiles` → 插入 `wallets`（余额 0），任一步失败整体回滚。

## 附录：建表 SQL（MySQL 8.0）

```sql
CREATE DATABASE IF NOT EXISTS ai_portal
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE ai_portal;

CREATE TABLE users (
  id              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  username        VARCHAR(50)     NOT NULL,
  password_hash   VARCHAR(255)    NOT NULL,
  role            VARCHAR(20)     NOT NULL DEFAULT 'user',
  status          TINYINT         NOT NULL DEFAULT 1,
  real_auth_status TINYINT        NOT NULL DEFAULT 0,
  school          VARCHAR(100)    DEFAULT NULL,
  created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_username (username),
  KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  COMMENT='用户主表';

CREATE TABLE user_profiles (
  id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id     BIGINT UNSIGNED NOT NULL,
  nickname    VARCHAR(50)     DEFAULT NULL,
  avatar_url  VARCHAR(255)    DEFAULT NULL,
  phone       VARCHAR(20)     DEFAULT NULL,
  email       VARCHAR(100)    DEFAULT NULL,
  major       VARCHAR(100)    DEFAULT NULL,
  bio         VARCHAR(500)    DEFAULT NULL,
  created_at  DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  COMMENT='用户资料表';

CREATE TABLE wallets (
  user_id         BIGINT UNSIGNED NOT NULL,
  balance         BIGINT          NOT NULL DEFAULT 0,
  total_recharged BIGINT          NOT NULL DEFAULT 0,
  total_consumed  BIGINT          NOT NULL DEFAULT 0,
  version         INT             NOT NULL DEFAULT 0,
  created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  COMMENT='钱包表';
```
